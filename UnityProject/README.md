# Подготовка проекта Unity

В этой папке находятся первые скрипты C# и инструкции по их подключению. Это ещё не полный проект Unity и не готовый APK: для сборки необходимо добавить сам проект Unity, закрепить версии пакетов, создать сцену и подключить необходимые комплекты разработки.

## Необходимые пакеты

- Система ввода Unity (Input System)
- Модуль OpenXR для Unity
- Meta XR Core SDK
- Meta XR Interaction SDK и официальные примеры Meta

Перед началом сборки необходимо выбрать совместимые версии пакетов и зафиксировать их в настройках проекта.

## Подключение сцены

1. Создать VR-сцену для Quest и настроить сборку под Android / ARM64.
2. Добавить `VovanderLocomotion` на корневой объект игрока. Назначить действие Vector2 для левого стика: горизонтальное движение поворачивает игрока, вертикальное перемещает вперёд и назад.
3. Добавить `VovanderMapToggle`, назначить кнопку B правого контроллера и объект виртуальной карты.
4. Добавить `VovanderRebindingManager` на объект настроек и заполнить список действий, для которых разрешено переназначение кнопок.
5. Добавить локальные модели левого и правого контроллеров Meta из официальных ресурсов Meta, если условия лицензии разрешают включение этих ресурсов в приложение. Подключить готовые анимации из официальных примеров.

## Модели контроллеров Meta

Главное требование — модели контроллеров должны находиться внутри APK и отображаться без загрузки из сети. Системные модели Quest можно предусмотреть как дополнительный вариант, но приложение не должно зависеть только от них.

Подробности приведены в документе `docs/CONTROLLER_MODELS_BUNDLED.md`.

## Обязательное правило для комментариев в исходном коде

Все комментарии в исходниках должны быть написаны только на русском языке и быть понятными человеку без опыта программирования.

- У каждой процедуры и функции должно быть пояснение, что она делает.
- Важные переменные, настройки и параметры должны быть объяснены.
- Сложные участки кода и причины нестандартных решений необходимо пояснять рядом с ними.
- Комментарии должны простыми словами объяснять смысл действий, а не просто повторять название команды.
- Новые и изменяемые скрипты необходимо проверять на соблюдение этого правила.

Названия классов, методов и переменных могут оставаться на английском языке для совместимости с Unity и C#.
