# Стандарт комментариев в исходном коде Vovander VR

Это обязательное правило для всех новых скриптов и любых изменений существующего кода.

1. Все комментарии в исходниках — строго на русском языке.
2. Перед каждой процедурой и функцией должно быть понятное пояснение её назначения.
3. Важные переменные, параметры, настройки и поля Inspector должны быть объяснены.
4. Нестандартные алгоритмы, проверки, ограничения и причины технических решений нужно комментировать рядом с кодом.
5. Писать простым языком, понятным человеку без опыта программирования. Не ограничиваться пересказом названия метода.
6. Не оставлять англоязычные комментарии. Английские названия API, классов и методов в самом коде не переводить.
7. При редактировании старого файла приводить комментарии изменённой части к этому стандарту; при существенной переработке — проверять весь файл.
8. Перед коммитом просматривать файл и проверять, что комментарии соответствуют правилу.

Пример хорошего комментария:
`// Игнорируем небольшие колебания стика, чтобы персонаж не двигался сам по себе.`

Пример плохого комментария:
`// Update player position.`
